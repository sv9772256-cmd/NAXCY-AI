# ✨ NAXCY AI PRO

AI-powered image and video enhancement application.

## 🚀 Features

- Fast Mode and Quality Mode
- Image enhancement
- Video enhancement
- Multiple output resolutions: 720p, 1080p, 2K and 4K
- Aspect ratio selection
- Sharpness adjustment
- Noise reduction
- Color, brightness and contrast controls
- Original video audio track preservation
- Processing progress indicator

## 🛠️ Built With

- Python
- Streamlit
- OpenCV
- FFmpeg

## 📖 How to Use

1. Upload an image or video.
2. Choose your enhancement settings.
3. Select Fast Mode or Quality Mode.
4. Click the Enhance button.
5. Preview and download the result.

## ⚠️ Important Notes

- Processing speed depends on video length, resolution, frame rate and server resources.
- Motion blur cannot always be removed completely.
- Enhancement quality depends on the source media.
- Audio is preserved through re-encoding and may not be bit-for-bit identical to the original.
